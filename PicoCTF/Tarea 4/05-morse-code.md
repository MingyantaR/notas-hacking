## Descripcion
Morse code is well known. Can you decrypt this? Download the file [here](https://artifacts.picoctf.net/c/79/morse_chal.wav). Wrap your answer with picoCTF{}, put underscores in place of pauses, and use all lowercase.
## Solucion
El reto nos da un codigo morse, lo descargamos y usamos esta pagina para descifrarlo: https://morsecw.com/decodificador.html

el resultado es este texto: WH47 H47H 90D W20U9H7

ahora el reto nos dice que usemos picoCTF{} y que en vez de espacios usemos guiones bajos, entonces queda asi:
picoCTF{wh47_h47h_90d_w20u9h7}
