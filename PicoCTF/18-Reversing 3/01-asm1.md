## Descripcion
What does asm1(0x3ef) return? Submit the flag as a hexadecimal value (starting with '0x'). NOTE: Your submission for this question will NOT be in the normal flag format. [Source](https://challenge-files.picoctf.net/c_fickle_tempest/2495cb38ce287ca8ea254d897188445d80871d1385e00fb7fa65dd5904747b41/test.S)
## Solucion
descargamos el archivo del reto y revisamos el contenido:
```
┌──(min㉿WIN-U49VUBQG3G3)-[~]
└─$ cat test.S
asm1:
        <+0>:   endbr32
        <+4>:   push   ebp
        <+5>:   mov    ebp,esp
        <+7>:   cmp    DWORD PTR [ebp+0x8],0x6e6
        <+14>:  jg     0x11d3 <asm1+38>
        <+16>:  cmp    DWORD PTR [ebp+0x8],0x8
        <+20>:  jne    0x11cb <asm1+30>
        <+22>:  mov    eax,DWORD PTR [ebp+0x8]
        <+25>:  add    eax,0x9
        <+28>:  jmp    0x11ea <asm1+61>
        <+30>:  mov    eax,DWORD PTR [ebp+0x8]
        <+33>:  sub    eax,0x9
        <+36>:  jmp    0x11ea <asm1+61>
        <+38>:  cmp    DWORD PTR [ebp+0x8],0x8f8
        <+45>:  jne    0x11e4 <asm1+55>
        <+47>:  mov    eax,DWORD PTR [ebp+0x8]
        <+50>:  sub    eax,0x9
        <+53>:  jmp    0x11ea <asm1+61>
        <+55>:  mov    eax,DWORD PTR [ebp+0x8]
        <+58>:  add    eax,0x9
        <+61>:  pop    ebp
        <+62>:  ret
```
al principio del codigo vienen 2 lineas que es la preparacion de la memoria:
```
push   ebp
mov    ebp, esp
```
con el valor inicial del reto, el 0x3ef la primera comparacion es:
```
<+7>:   cmp    DWORD PTR [ebp+0x8],0x6e6
<+14>:  jg     0x11d3 <asm1+38>
```
0x3ef es menor que 0x6e6, como no es mayor el codigo ignora el salto y sigue a la linea 16:
```
<+16>:  cmp    DWORD PTR [ebp+0x8],0x8
<+20>:  jne    0x11cb <asm1+30>
```
aqui compara el 0x3ef con 0x8 como si son diferentes (jne) realiza el salto a la direccion <+30>
```
<+30>:  mov    eax,DWORD PTR [ebp+0x8]
<+33>:  sub    eax,0x9
```
aqui pasa el valor de 0x3ef al registro eax y le resta 0x9
entonces queda 0x3ef -0x9 = 0x3e6
entonces ahora pasa a la siguiente linea:
```
<+36>:  jmp    0x11ea <asm1+61>
...
<+61>:  pop    ebp
<+62>:  ret
```
y aqui salta al final, limpia la pila y retorna lo que queda en eax, al final nos quedo 0x3e6 entonces esta es la flag```
