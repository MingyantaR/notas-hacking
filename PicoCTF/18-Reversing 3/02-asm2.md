## Descripcion
What does asm2(0x8,0x2e) return? Submit the flag as a hexadecimal value (starting with '0x'). NOTE: Your submission for this question will NOT be in the normal flag format. [Source](https://challenge-files.picoctf.net/c_fickle_tempest/e52eb78a50fe37d5d90fa3200de17edb7b6e51a3e01c583cec0ed94d9e9bc306/test.S)
## Solucion
descargamos y revisamos el archivod el reto:
```
┌──(min㉿WIN-U49VUBQG3G3)-[~]
└─$ cat test.S.1
asm2:
        <+0>:   endbr32
        <+4>:   push   ebp
        <+5>:   mov    ebp,esp
        <+7>:   sub    esp,0x10
        <+10>:  mov    eax,DWORD PTR [ebp+0xc]
        <+13>:  mov    DWORD PTR [ebp-0x4],eax
        <+16>:  mov    eax,DWORD PTR [ebp+0x8]
        <+19>:  mov    DWORD PTR [ebp-0x8],eax
        <+22>:  jmp    0x11d0 <asm2+35>
        <+24>:  add    DWORD PTR [ebp-0x4],0x1
        <+28>:  add    DWORD PTR [ebp-0x8],0xed
        <+35>:  cmp    DWORD PTR [ebp-0x8],0xe6da
        <+42>:  jle    0x11c5 <asm2+24>
        <+44>:  mov    eax,DWORD PTR [ebp-0x4]
        <+47>:  leave
        <+48>:  ret
```
vemos que vienen varias instrucciones en ensamblador
nuestros datos de entrada son: asm2(0x8, 0x2e)
en la linea +7:
```
<+7>: sub esp,0x10
```
se reserva espacio para variables locales y se indexan restandole a ebp:
ebp-0x4 = Variable Local 1
ebp-0x8 = Variable Local 2
ahora empezamos con la linea 10:
```
<+10>:  mov    eax,DWORD PTR [ebp+0xc]   ; eax = 0x2e
<+13>:  mov    DWORD PTR [ebp-0x4],eax   ; Local_1 = 0x2e

<+16>:  mov    eax,DWORD PTR [ebp+0x8]   ; eax = 0x8
<+19>:  mov    DWORD PTR [ebp-0x8],eax   ; Local_2 = 0x8
```
Local_1 (ebp-0x4) empieza valiendo 0x2e
Local_2 (ebp-0x8) empieza valiendo 0x8
ahora en la linea 22:
```
<+22>: jmp 0x11d0
```
el codigo salta las operaciones y va directo a revisar la condicion del bucle en la linea +35
```
<+35>:  cmp    DWORD PTR [ebp-0x8],0xe6da
<+42>:  jle    0x11c5 <asm2+24>
```
compara local_2 con 0xe6da y si local_2 es <= que 0xe6da, salta a <+24>
y en la linea 24 tenemos:
```
<+24>:  add    DWORD PTR [ebp-0x4],0x1
<+28>:  add    DWORD PTR [ebp-0x8],0xed
```
local_1 = local_1 + 1 y local_2 = local_2 + 0xed
bueno este bucle se va a repetir mientras local_2 sea menor o igual a 0xe6da cada ciclo local_2 aumenta en 0xed y local_1 aumenta en 1, es decir el numero de ciclos del bucle es lo que se le va a sumar a local_1
entonces tenemos que local_2 inicial = 8, limite maximo es 0xe6da = 59098 y el incremento por vuelta es 0xed = 237
entonces tenemos que saber cuantas veces tenemos que sumar 237 a 8 para superar los 59098 
entonces 59090 / 247 nos da 249.32
como tenemos un jle es decir salto si es menor o igual, cuando llegue a la vuelta 249, el valor todavia sera menor o igual al limite dara una ultima vuelta para superar este y romper el bucle entonces el total de vueltas es 250 que en hexa es 0xfa
y al final tenemos esto:
```
<+44>:  mov    eax,DWORD PTR [ebp-0x4]   ; eax = Local_1
<+47>:  leave
<+48>:  ret
```
entonces al final local_1 tenia 0x2e como valor inicial a esto se le suma 0xfa y nos queda como 0x128 y esta es nuestra bandera
